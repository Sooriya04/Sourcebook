# Future Notebook Pipeline

The Future Notebook Pipeline outlines Phase 3 and Phase 4 of the SourceBook roadmap, focusing on persistent SQLite storage, local vector indexing, and multi-modal ingestion.

## 🔮 Planned Enhancements

1. **SQLite + Local Vector Indexing**: Persistent storage for notebooks, sources, and vector embeddings.
2. **Multi-Modal Document Ingestion**: Ingesting YouTube transcripts, local PDFs, MP3/Audio files, and Markdown notes.
3. **Audio Overview Synthesis**: Generating 2-host podcast dialogues synthesized using local TTS (Kokoro/Piper).
4. **Multi-Turn Memory**: Maintaining persistent chat context across user notebook sessions.
