# Contributing to SourceBook

Thank you for your interest in contributing to SourceBook! We welcome community contributions to make SourceBook the premier open-source, local-first intelligence workspace.

## Development Workflow

1. **Fork and Clone**:
   ```bash
   git clone https://github.com/Sooriya04/Sourcebook.git
   cd Sourcebook
   ```

2. **Environment Setup**:
   ```bash
   cp .env.example .env
   ```

3. **Running the Application**:
   - Backend & Microservices: `./run.sh`
   - Frontend Dev Server: `cd ui && npm install && npm run dev`

## Architectural Guidelines

- **Modularity**: Keep new Go files and React components small, focused, and under 200 lines whenever possible.
- **Privacy & Grounding**: Ensure all answers generated by the LLM use grounded numerical citations (`[1]`, `[2]`).
- **Sanitization**: Always run external or scraped content through `utils.CleanText()`.
- **Zero Committed Secrets**: Never commit real API keys, environment files (`.env`), or SQLite databases.

## Pull Request Guidelines

- Ensure `go build ./cmd/server/main.go` and `npm run build` in `ui/` succeed without errors.
- Reference related issues in your PR description.
